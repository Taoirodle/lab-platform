Install the Admin Portal on this PC

The Admin Portal is the control surface for your L.A.B — approvals, AI controls, and fleet. This installer claims this computer as an administrator station and provisions its physical security key.

Provision your security key

Your Portal is protected by a physical key, not just a password. Download your key file below and save it onto a USB stick or fob — this becomes the key that unlocks the Portal. Keep it somewhere only you control.

lab-admin.key
Bound to this server · unique to you · unlocks the Admin Portal
Important. Anyone with this file and network access to your L.A.B can open the Admin Portal. Store it on removable media and remove it when you're done. It is never kept on this PC.

Install the Portal

Choose how to run the Admin Portal on this station. Both connect to your L.A.B over the local network and unlock with the key you just provisioned.

Open as an app Recommended

Runs the Portal in your browser and pins it to your desktop like a native app — cross-platform, always up to date. After it opens, use your browser's Install / Add to desktop option.

Desktop build (Windows) Optional

Run the packaged Electron Portal from a station that has the L.A.B app files. Paste this in PowerShell from the project folder:

./lab-admin-portal/launch.ps1

Admin Portal installed

This station is now an administrator for your L.A.B. Open the Portal and unlock it with your USB key whenever you need to run things.
